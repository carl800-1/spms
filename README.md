# 备件仓库管理系统 v2.0（桌面版 / 独立 exe）

**v2.0 是一个打包好的桌面程序**（基于 Electron）。双击 `备件仓库管理系统_v2.0.exe` 即可使用，**无需安装、无需联网、无需浏览器**，所有数据保存在本机文件里。

> 与之对应的是 `1.0/` 文件夹里的**网页版**（双击 `1.0/index.html` 在浏览器打开）。两者功能与界面完全一致，区别只在「交付形态」和「数据存放位置」（见下文「与 1.0 的区别」）。

## 功能模块

与 1.0 完全相同，共 8 个模块：

| 模块 | 说明 |
| --- | --- |
| 仪表盘 | 备品种类、预警、缺货、今日流水统计；库存预警清单；最近流水 |
| 备品管理 | 备品信息的录入、编辑、删除、查询（编号/名称/规格/分类/单位/库位/安全库存/当前库存/备注）；支持 CSV 模板批量导入与导出 |
| 入库管理 | 登记入库（备品、数量、经办人、供应商、时间、备注），自动增加库存 |
| 出库管理 | 登记出库（备品、数量、经办人、领用人/用途、时间、备注），自动扣减库存，库存不足时拦截 |
| 库存管理 | 实时显示各备品当前库存，低于安全库存自动标「预警」，缺货标「缺货」；支持只看预警、搜索、导出 |
| 库位管理 | 按库位汇总与筛选，点击库位查看其下备品 |
| 盘点 | 扫码/选择备品 → 录入实盘数量 → 显示系统库存与差异 → 确认校正库存并留痕（记录可在「记录查询」按"盘点"筛选） |
| 记录查询 | 按类型 / 时间范围 / 备品名称 / 经办人筛选出入库与盘点历史，支持导出 CSV |
| 数据备份 | 导出全部数据为 JSON 备份；导入备份恢复；清空数据（危险） |

## 二维码功能（离线）

系统已内置二维码**生成**（`qrcode-generator`）与**解码**（`jsQR`）库到 `js/vendor/`，**完全离线、无需联网**。

- **编码规范**：二维码只承载备品唯一编号，格式 `SPMS1|<编号>`（如 `SPMS1|BJ-001`）。名称/规格等由系统按编号实时查库补全（原因：纯 ASCII 扫描最稳、码更小、且更名不影响旧码）。
- **生成标签**：「备品管理」每行「二维码」可预览/下载单张 PNG；顶部「批量打印标签」可一次性生成全部备品的标签（二维码 + 编号/名称/规格/库位文字），用系统打印到标签纸。
- **扫码作业**：「入库 / 出库 / 盘点」均提供「📷 扫码选备品」按钮，识别后自动选中对应备品，后续录入流程不变。
  - **上传图片识别**：对标签拍照后上传即可识别，**离线可用**，是 exe 内的主用方式。
  - **摄像头实时扫码**：受桌面环境安全上下文限制，exe 内默认**隐藏摄像头入口**、仅保留上传图片（与 1.0 直接双击 `file://` 打开时的行为一致），不影响作业。

## 与 1.0 的区别

| 维度 | 1.0 网页版 | 2.0 桌面版（本目录） |
| --- | --- | --- |
| 启动方式 | 浏览器双击 `1.0/index.html` | 双击 `备件仓库管理系统_v2.0.exe` |
| 数据存储 | 浏览器 IndexedDB / localStorage（清缓存/换浏览器会丢） | **本机 JSON 文件**（随程序、不随浏览器，更可靠） |
| 联网需求 | 无 | 无 |
| 依赖集成 | 无需安装 | 已打包进 exe，无需安装运行环境 |
| 功能/界面 | 8 大模块 + 二维码 | 完全相同 |

## 使用方法（exe）

1. 将 `备件仓库管理系统_v2.0.exe` 复制到你常用的任意位置（如桌面或 `D:\工具\`）。
2. **双击运行**即可，无需安装。首次启动为 1280×820 窗口，标题「备件仓库管理系统 v2.0」。
3. 首次使用建议：在「备品管理」点击 **下载模板**，按模板填写约 600 种备品后 **导入 CSV**。
4. 日常通过「入库管理 / 出库管理」登记业务，库存自动变化；「库存管理」查看预警；「记录查询」追溯历史并导出。
5. 仪表盘顶部「数据存储方式」会显示「本地文件（JSON）」，确认系统已正常启动。

## 数据说明（重要）

- v2.0 的数据保存在本机用户数据目录：

  ```
  Windows: %APPDATA%\备件仓库管理系统\spms\spms-data.json
  ```

  （即 `C:\Users\<你的用户名>\AppData\Roaming\备件仓库管理系统\spms\spms-data.json`）

- 该文件是普通 JSON，**可整文件复制备份**；也可在程序内「数据备份」中导出/导入业务数据 JSON。
- 卸载或换电脑时，记得先「数据备份」导出，再在另一台机器「导入备份恢复」。
- 如担心数据安全，建议固定使用同一台电脑。

## 本地构建（开发/二次打包）

需要 Node.js 18+ 与 npm。在本目录执行：

```bash
# 1) 安装依赖（国内可加镜像加速 electron 二进制下载）
npm install

# 2) 打包为独立 exe（portable，产物在 release/）
npm run build
```

构建完成后在 `release/` 得到 `备件仓库管理系统_v2.0.exe`（单文件、免安装、可携式运行）。

### 国内镜像 / 受限网络说明

- **加速 electron 二进制下载**（可选）：
  ```bash
  set ELECTRON_MIRROR=https://cdn.npmmirror.com/binaries/electron/
  set ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
  npm install
  ```
- **若 `npm install` 下载 electron 运行时二进制失败**（典型报错 `ECONNRESET` / `node install.js` 失败），可跳过二进制下载、改用手动放置：
  ```bash
  # 先只装 JS 依赖，不下载 electron 运行时
  set ELECTRON_SKIP_BINARY_DOWNLOAD=1
  npm install
  # 用浏览器/curl 手动下载对应版本 zip（示例为 31.0.0 / win32-x64），解压到：
  #   node_modules/electron/dist/
  # 并新建 node_modules/electron/path.txt，内容仅一行：electron.exe
  ```
- **打包工具 `app-builder` 缺失时**：`npm install app-builder-bin` 即可从 npm registry 拉取（无需外网 CDN）。

## 常见问题

- **exe 启动后空白 / 点不了？** 正常不会。若异常，请将窗口内显示的红色错误提示发我；该程序已做全局兜底，任何 JS 错误都会显式渲染到页面而非白屏。
- **导入 CSV 中文乱码？** 用 Excel 另存为 CSV（UTF-8）后导入；系统导出已带 UTF-8 BOM，Excel 可直接打开。
- **想多人共享 / 集中管理？** 当前为单机桌面版。如需多人集中访问，需要改为带后端（如 Node + 数据库）的版本。
- **数据存在哪、怎么备份？** 见上文「数据说明」。推荐定期在「数据备份」导出 JSON，或直接复制 `spms-data.json`。
